# Tensorizer API

This Space runs the backend of [Tensorizer](https://jackyko1991.github.io/tensorizer/): it re-renders physics
problems with your parameters, one at a time through a queue. The website itself is hosted on GitHub Pages.

Source: https://github.com/jackyko1991/tensorizer — deployed automatically from `main`.
